### 🚀 Projetos em destaque

#### 🔑 [Auth API](https://github.com/SantoBug/auth-api)
API de autenticação stateless com JWT e controle de acesso por papéis.

- Access token + refresh token, com expiração e rotação configuráveis
- Autorização por role (`RBAC`) em nível de endpoint via `Spring Security`
- Documentação interativa com Swagger/OpenAPI
- Suíte de testes com JUnit + Mockito cobrindo o fluxo de autenticação
- Containerizado com Docker para subir o ambiente em um comando

`Java` `Spring Boot` `Spring Security` `JWT` `MySQL` `Docker` `JUnit/Mockito`

#### ⚡ Task API
API de gerenciamento de tarefas otimizada com cache.

- CRUD completo com cache em Redis para reduzir leitura no banco em consultas repetidas
- Arquitetura em camadas (Controller → Service → Repository)
- Persistência com MySQL via JPA

`Java` `Spring Boot` `Redis` `MySQL` `JPA`
